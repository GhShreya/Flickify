# Flickify

## Movie Ticket Booking Website

Implemented using MERN Stack.
It features Clerk for seamless authentication and user management, Inngest for reliable background jobs and serverless workflows, and is deployed effortlessly on Vercel for optimized global delivery.

In this full stack project, user can signup, explore the movies and book the tickets. While booking tickets, user can choose their preferred seats.
It also has the admin dashboard, where admin can add new movies and manage the bookings.
